# 🌸 SkinIQ – AI-Powered Skin Health Monitoring Platform

SkinIQ is a web-based application designed to help users understand and manage their skin health using artificial intelligence. The system provides AI-based skin analysis, personalized skincare routines, product compatibility checking, and routine reminders through a modern and user-friendly interface.

This project is developed as a **Final Year Project** and focuses on combining **AI models, web technologies, and cloud services** to create an intelligent skincare assistant.

---

## 🚀 Features

* User registration and login
* Role-based access (Admin, User)
* User profile and skin profile management
* AI skin image analysis (skin type & acne detection)
* AI-generated skincare report
* Personalized skincare routine generator
* Skincare product compatibility checker
* AI chat assistant for skincare guidance
* SMS routine reminder notifications
* User dashboard with summarized insights
* Image upload and secure storage

---

## 🧠 AI Components

* Skin type classification model
* Acne detection model
* AI-based decision logic for routines and reports

The AI models are implemented using **Python and TensorFlow** and integrated with the frontend through APIs.

## ⚙️ Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/your-username/skiniq.git
```

2. Navigate to the project directory

```bash
cd SkinIQ
```

3. Install dependencies

```bash
npm install
```

4. Run the development server

```bash
npm run dev
```

5. Configure Firebase

* Create a Firebase project
* Enable Authentication, Firestore, and Storage
* Add your Firebase configuration to `firebase.js`
